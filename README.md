# Popcorn Time (Next.js + Bun)

This is a Next.js app bootstrapped with `create-t3-app`, using **Bun** as the package manager.

## Development

Install deps:

```bash
bun install
```

Run dev server:

```bash
bun run dev
```

Build / start:

```bash
bun run build
bun run start
```

Lint:

```bash
bun run lint
```

Follow our deployment guides for [Vercel](https://create.t3.gg/en/deployment/vercel), [Netlify](https://create.t3.gg/en/deployment/netlify) and [Docker](https://create.t3.gg/en/deployment/docker) for more information.
